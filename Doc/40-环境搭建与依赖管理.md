# 环境搭建与依赖管理

> 状态：草案（脚手架实施期为 M0，本文随依赖变化同步维护）
> 最后更新：2026-10-12

## 1. 前置条件

| 项 | 要求 | 说明 |
| --- | --- | --- |
| Python | >= 3.13 | 未安装时优先用 uv 自动下载管理 |
| uv | 最新稳定版 | 推荐；无 uv 时走 venv 备选路径 |
| Git | 任意近期版本 | 需正确配置换行（`.gitattributes`）与大小写敏感策略；仓库初始化与提交/推送规范见 `30` 第 8 节 |
| ffmpeg / ffprobe | 待 M2 确定最低版本 | 视频转码与探测 |
| exiftool | 待 M2 确定最低版本 | 元数据读取与写入 |
| hdc | 随 DevEco / HarmonyOS SDK | 鸿蒙真机文件拉取（M1 验证后确认） |
| adb | 后续 Android 方向需要 | 暂不强制 |

外部工具版本区间在 M2 转码矩阵验证后回填（见第 5 节表格"最低版本"列）。

### 1.0 M1 前需要手动完成的事项（使用者）

以下事项涉及设备安装与系统配置，setup 脚本无法代劳，必须由使用者手动完成。

1. **安装 hdc 并加入 PATH**：从 HarmonyOS 命令行工具包或 DevEco Studio 获取，把其中的 `toolchains` 目录加入 PATH。
   不便修改 PATH 时可用环境变量指定：`$env:LPCONV_HDC_PATH = "<hdc.exe 完整路径>"`（macOS 用 `export LPCONV_HDC_PATH=...`）。
2. **设备侧授权**：开启开发者模式与「USB 调试」，连接数据线后在设备上确认 RSA 授权弹窗（勾选"始终允许"）。
   验证：`hdc list targets -v`，USB 设备状态应为 `Connected`；显示 `Unauthorized` 说明未授权，需在设备上确认或"撤销 USB 调试授权"后重插。
3. **安装 ffmpeg / ffprobe / exiftool**：Windows 执行 `scripts\setup.ps1 -InstallTools`（winget），macOS 执行 `INSTALL_TOOLS=1 bash scripts/setup.sh`（brew）。
4. **iOS 设备**：Windows 需安装 iTunes 或 Apple 设备支持，使 Apple Mobile Device Service 处于运行状态。

### 1.1 本机环境注意事项（Windows）

- **PATH 中的 `python` 指向 3.11，而项目要求 3.13**：Python 3.13 已安装，但需用 `py -3.13` 调用（py launcher 默认即为 3.13）。仓库根已放置 `.python-version`（内容 `3.13`），uv 会据此选择解释器，不受 PATH 顺序影响。
- **`uv python list` 会报错**：PATH 中存在不可用的 `~/.local/bin/python3.12.exe`（不受信任的装入点）。因已固定 `.python-version`，`uv sync` 等命令不受影响，无需处理该链接。
- **控制台编码**：Windows 控制台默认按 GBK 解码，CLI 已强制 UTF-8 输出；若中文仍乱码，先执行 `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8`。`scripts/setup.ps1` 已内置该设置。

## 2. 脚本目录（已确认）

顶层 `scripts/` 用于存放环境初始化与工程辅助脚本：

```
scripts/
├── setup.ps1     Windows 一键环境初始化
├── setup.sh      macOS / Linux 一键环境初始化
└── common/       两平台共享的检测逻辑（版本比对、依赖清单）
```

若确认不新增顶层目录，则退化为 `Src/scripts/`，但需在 `pyproject.toml` 中排除打包。

## 3. Windows 初始化（PowerShell）

```powershell
# 若系统禁止运行脚本，仅对当前进程放宽：
powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1
```

`setup.ps1` 应完成的步骤：

1. 检查 Python >= 3.13；缺失则提示安装或用 `uv python install 3.13`；
2. 检查 uv；缺失则提示 `winget install astral-sh.uv` 或使用官方安装脚本；
3. `uv sync`（创建 `.venv` 并安装依赖组，含 dev）；
4. 导出 `requirements.txt` / `requirements-dev.txt`（供 pip 用户）；
5. 检测外部工具（ffmpeg / ffprobe / exiftool / hdc），缺失时给出安装指引；可选参数 `-InstallTools` 通过 winget 自动安装 ffmpeg/exiftool；
6. 创建 `Tmp/` 与 `Log/`；
7. 执行 `uv run lpconv doctor` 打印环境报告。

## 4. macOS 初始化（Shell）

```bash
bash scripts/setup.sh
```

`setup.sh` 步骤与 Windows 对齐：

1. 检查 Python（Homebrew 或 `uv python install 3.13`）；
2. 检查 uv（`brew install uv` 或官方脚本）；
3. `uv sync`；
4. 导出 requirements；
5. 检测外部工具（可通过 `brew install ffmpeg exiftool` 自动安装，需显式确认）；
6. 创建 `Tmp/` 与 `Log/`；
7. `uv run lpconv doctor`。

## 6. 常用命令

```bash
uv sync                     # 安装/同步依赖（含 dev）
uv add <pkg>                # 新增运行时依赖
uv add --dev <pkg>          # 新增开发依赖
uv export --no-dev --no-hashes --format requirements-txt -o requirements.txt
uv export --no-hashes --format requirements-txt -o requirements-dev.txt
uv run lpconv doctor        # 环境自检（Python / 外部工具 / 目录）
uv run pytest               # 测试
uv run ruff check . && uv run ruff format .
uv run mypy Src             # 类型检查
```

备选（无 uv）：

```bash
py -3.13 -m venv .venv          # Windows：注意 PATH 中的 python 可能是 3.11
python3.13 -m venv .venv        # macOS
pip install -r requirements-dev.txt
```

## 7. FAQ

| 现象 | 处理 |
| --- | --- |
| PowerShell 提示禁止运行脚本 | 使用 `-ExecutionPolicy Bypass` 或对当前用户设置 `RemoteSigned` |
| macOS 提示工具无法验证开发者 | 系统设置 → 隐私与安全性 → 允许；或用 `xattr -d com.apple.quarantine <path>` |
| uv / pip 下载慢 | 配置镜像源（uv 用 `UV_INDEX_URL`，pip 用 `-i`），不要提交个人镜像配置 |
| 中文输出乱码 | Windows 控制台默认按 GBK 解码；CLI 已强制 UTF-8 输出，仍乱码时先执行 `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8`（`scripts/setup.ps1` 已内置） |
| 子进程输出在测试中解码失败 | 测试里用 `subprocess` 捕获输出时必须显式 `encoding="utf-8"`，否则按本地代码页解码会抛 `UnicodeDecodeError` |
| Windows 与 macOS 行为不一致 | 先跑 `lpconv doctor`，比对外部工具版本；差异项按 `30` 规范修正而不是加平台分支绕过 |
| 目录大小写导致 Git 异常 | 按 N3.7，禁止变更大小写；必要时用 `git mv` 两步改名 |
| 外部工具缺失导致中途失败 | 属 N6.5 违规，应补充 `doctor` 检测项 |
